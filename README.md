# Digital Humanities Demo - The Turtle
This demo provides an example of both digital text presentation and simple textual analysis. It consists of TEI-formatted XML data containing the public domain poem <i>Die Schildkröte</i> (<i>The Turtle</i>) by the German poet Christian Morgenstern.  	The German compound word "Schildkröte" literally breaks apart into "shield-toad." The XML is parsed and displayed using JavaScript and DOMParser, and the visuals are generated using the d3 package for JavaScript.  This demo is best viewed on a computer screen; second-best is landscape mode.
- <i>Bran Besalke</i>, May 2026
  
## Features
- Word-by-word English translation can be activated with the "Show  Translation Gloss" selection.
- The ABAB rhyme scheme can be highlighted with the "Highlight Rhymes" selection.
- A simple German-English dictionary gives dictionary-forms, part-of-speech information, and simple translations for words.  Click on a word in the poem to view that word's entry.
- Charts showing word distribution by part-of-speech and noun distribution by grammatical gender automatically adjusts based on which verses of the poem are toggled on.
