This demo consists of TEI-formatted XML data containing the public domain poem Die Schildkröte (The Turtle) by the German poet Christian Morgenstern. The German compound word "Schildkröte" literally breaks apart into "shield-toad." The XML is parsed and displayed using JavaScript and DOMParser, and the visuals are generated using the d3 package for JavaScript. This demo is best viewed on a computer screen; second-best is landscape mode.
- Bran Besalke, May 2026
